# Floorplan → 3D: фотореалистичные виды сверху по планировкам квартир

Конвейер, который превращает 2D-планировки квартир застройщика в
фотореалистичные 3D-визуализации «вид сверху» в едином эталонном стиле —
для сайта и рекламных материалов. Главное требование заказчика —
**полное соответствие плану**: стены, проёмы, окна, состав и расстановка
мебели, подписи площадей до цифры.

Генеративная модель сама по себе рисует красиво, но неточно: двигает стены,
добавляет двери, путает мебель и цифры. Поэтому проект — это не «промпт
к нейросети», а система вокруг неё: точная геометрия из кода, AI только
для фотореализма, автоматическая проверка результата по плану и
детерминированные правки там, где модель ошибается.

> Витринная версия коммерческого проекта: исходные планировки и готовые
> рендеры клиента не публикуются, пути и внутренние идентификаторы задач
> убраны.

## Как устроен конвейер

Подход развивался в три поколения — все три в репозитории:

1. **AI по плану + контроль геометрии.** План готовится (обрезка, отступы,
   карта размеров комнат), Nano Banana Pro (Gemini 3 Pro Image) в Google AI
   Studio рисует рендер по мастер-промпту и эталону стиля. Браузер управляется
   по Chrome DevTools Protocol — выделенная вкладка, загрузка файлов,
   скачивание результатов, пакетные прогоны. Каждый результат проверяется
   наложением линий плана и метрикой **wall IoU**; ошибки правятся локально:
   удаление объекта на кропе с выравниванием ECC и цветовой подгонкой,
   перерисовка области по соответствующему фрагменту плана, процедурные
   схемы гардеробных как точный шаблон.
2. **Своя 3D-сцена.** Стены берутся из изображения плана, мебель описывается
   списком в координатах плана (40 планировок) и рендерится движком на
   three.js в headless Chromium: ортографическая камера сверху,
   процедурные PBR-материалы (паркет, плитка, ткани), параметрическая
   библиотека мебели со складками ткани и контактными тенями.
3. **Blender + AI-фотореализм.** Точная геометрия плана строится в Blender
   (Cycles, своя библиотека мебели на bpy), поверх «глиняного» рендера AI
   делает фотореалистичный проход — целиком или по комнатам, несколько
   попыток, каждая оценивается по совпадению стен с Blender-геометрией,
   лучшая остаётся; точные стены накладываются сверху.

Подписи площадей и плашка квартиры рисуются кодом, а не моделью — цифры
всегда точные.

**Независимый AI-приёмщик.** [`tools/JUDGE.md`](tools/JUDGE.md) — инструкция
для отдельного агента-проверяющего: он сам ничего не правит, сравнивает рендер
с планом по зонам (наложение, сетка, 6–10 увеличенных фрагментов) и выдаёт
список конкретных исправлений по каждой комнате.

## Стек

Python · NumPy · OpenCV · Pillow · SciPy · Chrome DevTools Protocol (мост
на Node.js) · Gemini 3 Pro Image (Nano Banana Pro) · three.js · headless
Chromium · Blender 5 (bpy, Cycles) · Poly Haven API (текстуры)

## Структура

```
PROMPT_floorplan_3d.md   мастер-промпт и правила стиля
PROMPTS.md               рабочий процесс, промпты по планам, чек-лист приёмки
tools/
  cdp_bridge.js, cdp.py  мост к Chrome по CDP
  studio.py, gem.py      автоматизация AI Studio и Gemini
  overlay.py, wall_iou.py, grid.py   проверка рендера по плану
  ai_inpaint.py, plan_guided.py, fix.py, patch.py   локальные правки
  wardrobe_*.py          процедурные гардеробные
  labels.py              детерминированные подписи площадей
  JUDGE.md               инструкция AI-приёмщика
  scene3d/               сцены по планам и рендер на three.js
  engine/                движок рендера: камера, свет, материалы, мебель
  bl/                    Blender: библиотека мебели, сборка сцены, гибридный проход
```

Пути проекта заданы константами в скриптах (`/mnt/c/Projects/3d_visual`):
это рабочий инструмент, а не библиотека.
